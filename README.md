# TechZone Store

## Project Overview

TechZone Store is a Flutter shopping application developed using Dart and Flutter framework. The application allows users to browse technology products, view product details, and navigate between multiple screens using a modern user interface.

## Features

* Home Screen
* Products Screen
* Product Details Screen
* About Screen
* Bottom Navigation Bar
* Product Categories
* ListView.builder
* Network Images
* Responsive UI Design
* Simple MVC Architecture

## Project Structure

### Models

* ProductModel
* CategoryModel

### Controllers

* ProductController
* CategoryController

### Screens

* Splash Screen
* Home Screen
* Products Screen
* Details Screen
* About Screen
* Navigation Screen

## OOP Concepts Used

### Encapsulation

Data is organized inside model classes such as ProductModel and CategoryModel.

### Abstraction

Controllers manage data separately from the user interface.

## Technologies Used

* Flutter
* Dart
* Material Design

## Navigation

The application uses Bottom Navigation Bar for moving between screens and Navigator for opening the product details page.

## Data Handling

The products are stored in a list of ProductModel objects and displayed using ListView.builder.

## Images

The application uses network images to display product photos.
